# SEO сайта kadastrhelp.ru

Все, что описано ниже, бесплатно. Цены, сроки и юридические утверждения на сайт не выдумываются:
цены берутся из прайса владельца (`PRICE_ROWS` в `index.dc.html`), сроки — «по договору».

## Что уже сделано в коде

| Что | Где | Зачем |
|---|---|---|
| Копии страниц для роботов | `make-snapshots.mjs`, правила в `pack-hosting.mjs` | Страницы рисуются JavaScript-ом (списки услуг, шаги, FAQ, цены). Роботам поисковиков (Яндекс, Google, Bing, Mail.ru, Sputnik, DuckDuckGo, Apple) отдаётся готовый HTML того же адреса, посетителям — живая страница как раньше. Копии лежат в `_snap/`, снаружи этот адрес закрыт (403). |
| Структурированные данные | `seo-lib.mjs`, `seo-markup.mjs`, `gen-landings.mjs` | `Service` с ценой, `BreadcrumbList`, `FAQPage` на страницах услуг; `FAQPage` на главной. Строятся из тех же массивов, что и видимый текст. |
| Три страницы под узкие запросы | `landings-data.mjs` → `vynos-tochek`, `akt-obsledovaniya`, `akt-osmotra` | Услуги и цены уже были в прайсе, своих страниц не было. Ссылки: меню, подвал, названия в прайсе на главной, «Похожие услуги». |
| `sitemap.xml` с датой изменения | `pack-hosting.mjs` | `lastmod` = дата последнего коммита страницы. |
| Описание картинок | `index.dc.html`, `mezhevanie.dc.html` | Текст на слайде главной — часть картинки, поиск его не читает. |
| Проверка | `node tests/seo-check.mjs` | sitemap, canonical, JSON-LD, списки адресов, цены посадочных = прайс владельца. |

## Команды

```
node seo-markup.mjs          # пересобрать JSON-LD старых страниц и главной
node gen-landings.mjs        # пересобрать три посадочные из landings-data.mjs
node tests/seo-check.mjs     # проверка
node pack-hosting.mjs        # упаковка для reg.ru: копии для роботов, sitemap, .htaccess
```

Поменял FAQ или цену на странице — запусти `node seo-markup.mjs`. Поменял текст посадочной —
правь `landings-data.mjs` и запускай `node gen-landings.mjs` (руками `.dc.html` посадочных не править).

## Что нужно от владельца (сделать за него нельзя)

1. **Яндекс Вебмастер** (webmaster.yandex.ru): добавить `kadastrhelp.ru`, подтвердить права, отправить
   `https://kadastrhelp.ru/sitemap.xml`, в «Региональность» указать Самару. Подтверждение:
   - мета-тегом: строку `<meta name="yandex-verification" content="…" />` положить в файл
     `seo-verification.html` рядом с `pack-hosting.mjs` (попадёт в `<head>` всех страниц и копий для роботов), или
   - файлом: файл `yandex_….html`, который даст Вебмастер, положить в корень репозитория.
2. **Google Search Console**: то же самое (`google….html` в корень или мета-тег в `seo-verification.html`).
3. **Яндекс Бизнес** (business.yandex.ru): карточка организации. Нужны аккаунт Яндекс ID владельца,
   адрес офиса либо режим «выезд к клиенту» (адрес скрывается, указывается зона обслуживания),
   фото рабочего процесса (не стоковые), подтверждение звонком или кодом.
   В `sameAs` на главной уже указана карточка `yandex.ru/maps/org/159032999200/` (Стерлитамак,
   2 отзыва, ответов владельца 0). Если она ваша, ответить на отзывы и дополнить её, а не заводить дубль.
4. **2ГИС**: бесплатная карточка через форму для представителей (account.2gis.com).
5. **Отзывы**: просить реальных клиентов писать в карточках после работы. Вымышленные и купленные
   отзывы нельзя: карточку могут заблокировать.
6. **Счётчик Яндекс Метрики не ставили**: он собирает данные посетителей, а политика
   конфиденциальности (`politika.dc.html`) его не описывает. Сначала юрист/владелец дополняет политику.
