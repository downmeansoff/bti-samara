# Сайт БТИ Самара — ИП Баймурзин А. Р.

Лендинг кадастрового инженера. **К проекту Fortune VPN отношения не имеет** — это
отдельный сторонний проект, свой репозиторий, свои деплои.

## Как выкладывать

Двойной клик по `DEPLOY.bat` в корне: делает `git push origin main` (основная ссылка,
сборка GitHub Pages ~40 секунд) и `railway up --ci` (резервная, ~1 минута).
Из сессии Claude, запущенной в репозитории Fortune VPN, деплой блокирует его защитный хук —
выкладывает владелец батником.

⚠️ Не копировать файлы через `git archive`: при `core.autocrlf=true` он переводит
`assets/vendor/react*.min.js` в CRLF, хеш SRI перестаёт совпадать и страница остаётся пустой.

## Как устроен сайт

Client-rendered на **dc-runtime**: `support.js` разворачивает `<x-dc>`, `<dc-import>`,
`sc-for`, `sc-if`. Компоненты — `*.dc.html`, логика в `class Component extends DCLogic`.
Картинки-слоты — `image-slot.js` + `.image-slots.state.json` (dotfile с base64).

Раздаётся `server.js` — Node без зависимостей: слушает `$PORT`, `/` редиректит на
`index.dc.html`, HTML/JS отдаёт с `no-cache`, картинки на сутки.

Локально посмотреть:
```
PORT=3999 node server.js
```

**Режим правок** (26.09.2026). Ссылка с `?review=1` — например
`https://downmeansoff.github.io/bti-samara/?review=1` — включает поверх сайта панель
«Заметка / Рисунок / Отменить / Правки»: метки с текстом и картинкой, рисование пальцем или
мышью. Код — `assets/review.js`; в `<head>` пяти страниц однострочный загрузчик, который
тянет его только при `?review=1` или флаге `bti_review` в sessionStorage вкладки —
посетителям файл не грузится. Правки лежат в localStorage браузера, наружу — «Скопировать
текст» или файл `bti-pravki-*.json`. Скриншоты с метками по файлу:
`node C:/Users/glebo/bti-lab/tools/review-render.mjs` (без `--in` берёт свежий файл из
«Загрузок»). Проверка: `review-test.mjs` там же. Редирект с `/` (`index.html` и `server.js`)
сохраняет query — иначе ссылка с `?review=1` на корень теряла бы параметр.

**Вся вёрстка — в `assets/site.css`**: токены цветов и шрифтов, компоненты, адаптив.
Разметка страниц на классах.

`<title>`, description, `og:*`, иконка и canonical лежат в статическом `<head>`, а не в
`<helmet>`. Helmet вставляет теги JavaScript-ом, а боты превью ссылок (Telegram, WhatsApp,
ВК) JS не запускают — до 24.09.2026 из-за этого обложка в превью не показывалась.
В `<helmet>` остались только стили. У корневого `index.html` (редирект) свой набор og-тегов —
это его ссылку раздают. Canonical главной — `index.dc.html`, корень ведёт на него.

экраном убрали: она повторяла те же фото, что уже есть на странице. Подпись с именем поверх
фото не ставить — фото стоковые, это не он. ⚠️ У слотов `hero-home` и `about-portrait` в state сохранён сдвиг кадра
(x ≈ −29% и +23%). Он заполняет рамку, только если слот портретный, поэтому в CSS слот
всегда 4:5, а плитка вокруг обрезает лишнее. Сделать слот альбомным — вылезет пустая полоса.

Если когда-нибудь понадобится цепляться к inline-стилю: React сериализует его
**с пробелом после двоеточия** и переводит `0` в `0px`.

Версия до всех редизайнов — тег `pre-redesign`. Откат: `git revert` коммитов редизайна.

**Внешних зависимостей нет и добавлять нельзя** — аудитория российская. React и шрифты
лежат свои: `assets/vendor/react*.min.js`, `assets/fonts/`. Раньше тянулись с unpkg.com
и Google Fonts; при блокировке unpkg страница была бы полностью пустой.
Проверка: открыть сайт и убедиться, что внешних сетевых запросов ноль.

  `<head>`).

Окно заявки (`LeadModal.dc.html`) при отправке в Telegram-бота дополнительно копирует

нажать «Запустить» и вставить текст. Это подстраховка на случай, если клиент
Telegram не подставил `?text=` автоматически.

## Правила по контенту

- **Делать строго то, что прислал владелец.** Без самодеятельности в текстах, цифрах
  и блоках. Технические улучшения (превью ссылки, фавикон, мобильная панель) он не
  оспаривал, но содержимое — только по его списку.
- **Персональные данные замазывать.** В сканах документов были СНИЛС и дата рождения —
  закрыты чёрными плашками. Оригинальные PDF выписки СРО не публиковать.
- Правки в `.dc.html` — обычный inline-HTML, пересборка не нужна.
