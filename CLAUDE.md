# Сайт БТИ Самара — ИП Баймурзин А. Р.

Лендинг кадастрового инженера. **К проекту Fortune VPN отношения не имеет** — это
отдельный сторонний проект, свой репозиторий, свои деплои.

## Как выкладывать

Двойной клик по `DEPLOY.bat` в корне: делает `git push origin main` (основная ссылка,
сборка GitHub Pages ~40 секунд) и `railway up --ci` (резервная, ~1 минута).
Из сессии Claude, запущенной в репозитории Fortune VPN, деплой блокирует его защитный хук —
выкладывает владелец батником.

⚠️ Не копировать файлы через `git archive`: при `core.autocrlf=true` он переводит
`assets/vendor/react*.min.js` в CRLF, хеш SRI перестаёт совпадать и страница остаётся пустой.

## Как устроен сайт

Client-rendered на **dc-runtime**: `support.js` разворачивает `<x-dc>`, `<dc-import>`,
`sc-for`, `sc-if`. Компоненты — `*.dc.html`, логика в `class Component extends DCLogic`.
Картинки-слоты — `image-slot.js` + `.image-slots.state.json` (dotfile с base64).

Раздаётся `server.js` — Node без зависимостей: слушает `$PORT`, `/` редиректит на
`index.dc.html`, HTML/JS отдаёт с `no-cache`, картинки на сутки.

Локально посмотреть:
```
PORT=3999 node server.js
```

**Вся вёрстка — в `assets/site.css`** (с 23.09.2026, премиальный редизайн): токены цветов
и шрифтов, компоненты, адаптив. Разметка страниц на классах, инлайн-стилей почти нет.
Стиль «тёмная оболочка + тёплая бумага»: шапка, первый экран, «Что вы получите», финальный
призыв и подвал — тёмные; содержательные разделы — светлые. Акценты: изумрудный для кнопок,
латунный для цифр и тонких линий.
Старый блок мобильных правил в `Header.dc.html` на селекторах по inline-стилю удалён.
Если когда-нибудь снова понадобится цепляться к inline-стилю: React сериализует его
**с пробелом после двоеточия** и переводит `0` в `0px`.

Версия до редизайна — тег `pre-redesign`. Откат: `git revert` коммита редизайна.

**Внешних зависимостей нет и добавлять нельзя** — аудитория российская. React и шрифты
лежат свои: `assets/vendor/react*.min.js`, `assets/fonts/`. Раньше тянулись с unpkg.com
и Google Fonts; при блокировке unpkg страница была бы полностью пустой.
Проверка: открыть сайт и убедиться, что внешних сетевых запросов ноль.

## Правила по контенту

- **Делать строго то, что прислал владелец.** Без самодеятельности в текстах, цифрах
  и блоках. Технические улучшения (превью ссылки, фавикон, мобильная панель) он не
  оспаривал, но содержимое — только по его списку.
- **Персональные данные замазывать.** В сканах документов были СНИЛС и дата рождения —
  закрыты чёрными плашками. Оригинальные PDF выписки СРО не публиковать.
- Правки в `.dc.html` — обычный inline-HTML, пересборка не нужна.
